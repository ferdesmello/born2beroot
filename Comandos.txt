----sudo------------------
* status
sudo -V
sudo --version
sudo visudo -c

* regras
sudo visudo -f /etc/sudoers.d/42-born2beroot

"Defaults       passwd_tries=3
Defaults        badpass_message="Incorrect password. Please try again."
Defaults        logfile="/var/log/sudo/sudo.log"
Defaults        log_input,log_output
Defaults        requiretty"

passwd_tries=3: allow at most three password attempts.
badpass_message: display your custom message when authentication fails.
logfile: record sudo activity in the specified log file.
log_input,log_output: enable logging of command input and output.
requiretty: require sudo to run from a terminal.

* log existe?
sudo ls -la /var/log/sudo/

* histórico de logs
sudo cat /var/log/sudo/sudo.log

* checar últimos usos de sudo
sudo tail -n 5 /var/log/sudo/sudo.log

----UFW------------------
* status
sudo ufw status verbose

* regras ativas
sudo ufw status numbered

* incluir nova porta
sudo ufw allow <porta>

* excluir porta
sudo ufw delete <N da porta>

-------------------------
* block incoming connections
ufw default deny incoming

* allow outgoing connections
ufw default allow outgoing

* permit incoming SSH connections on port 4242
ufw allow 4242/tcp

----SSH------------------
* status
sudo systemctl status ssh

* regras
sudo nano /etc/ssh/sshd_config.d/42-born2beroot.conf
• Port 4242
• PermitRootLogin no

* fora da VM, no terminal
localhost pode ser o IP da máquina 127.0.0.1 ou descobrir com :
ip a (inet 192.168.1.15)
ip route show default (192.168.64.1)

* configure VirtualBox
Setting		Value
Protocol	TCP
Host IP		127.0.0.1
Host Port	4243
Guest IP	Leave blank
Guest Port	4242

* fora da VM, no terminal
ssh -p 4243 <user_login>@<localhost>

* fora da VM, no terminal (não funciona)
ssh -p 4243 root@<localhost>

apt -> "advanced package tool" (gerenciador de pacotes básico e simples do linux)
aptitude -> (gerenciador de pacotes mais complexo)
sudo -> "superuser do" (programa que permite um usuário comum executar comandos de privilégio, de root de maneira auditada)
LVM -> "logical volume manager" (camada entre disco real e o sistema de arquivos, gerencia os armazenamentos nos discos)
UFW -> "uncomplicated firewall" (gerenciador de firewall, controla o tráfego de rede e autorização de acesso)
SSH -> "secure shell" (protocolo de rede criptografado para gerenciar servidores remotamente)
APPArmor -> "application armor" (módulo de segurança do linux que controla acesso a recursos por grupos e usuários)
cron -> "cronos" (daemon agendador de tarefas)
crontab -> "cron table" (dados de horários para as a tarefas a serem executadas)
